# Piano Auto Sustain — 测试清单

来源：plan §7 验收标准（18 功能场景 + 用户实弹验收），另附极端情况（取材 plan §3.1/§3.2/§4.4 与 SDS 已知行为条款，逐行标注来源）。

**验证方法（先读）**：

- 需要检查 item 内 CC 的场景：用 **Input FX 法**——把插件放轨道 Input FX（监听 FX）区，实时弹奏录制，生成的 CC 随输入进 item；然后在 MIDI 编辑器查看 item 内目标 CC 轨道形态。
- 所有事件时刻断言允许 **±10ms 容差**（含 humanize_ms±2ms 断言与「抬-踩间隙 ≈ gap_ms + humanize_ms」断言）。
- 除注明外参数用默认值：gap=20、humanize=12、tail=2400、低音窗=250、重复音窗=120、上限=B3(59)。

## A. 功能场景（plan §7.1，场景 1–18）

| 编号 | 场景 | 操作步骤 | 预期结果 | 实测 | 备注 |

| 2 | 同和弦琶音（高音区） | 高音区以 150–250ms 间隔弹同和弦琶音；录制查看 | **不换踏**（结构保证） | | |
| 3 | 低音换和弦 | 左手弹低音区新音级（换和弦） | 立即换踏，抬-踩间隙 ≈ gap_ms + humanize_ms（收敛轮 IMP-4） | | 间隙断言 ±10ms 容差 |

| 7 | 硬件合并 | 一手踩住硬件踏板，另一手弹音触发自动换踏；再松开硬件踏板；全程看诊断页 | 硬件踩住时自动换踏不压掉硬件；硬件松开自动保持；诊断三值正确 | | 诊断页 硬件/自动/合成 |
| 8 | 简单模式全流程 | 和弦保护=关；弹音-延音-松手；再做重复音重击 | 踩-延-放，重复音重踏无效 | | UI 中重复音重踏灰置 |

| 10 | 尾音期间新音 | 全部松手进入尾音计时后：a) 弹高音新音；b) 弹低音新音级 | 取消计时；低音新音=换踏、高音新音=保持踩下（收敛轮 N-5） | | |
| 11 | 两按钮边界 | a) 踏板在下点「换踏一次」；b) 踏板在上点「换踏一次」；c) 点「释放踏板」观察挂起，再弹新音 | 换踏一次（下→切分/上→踩下/解除挂起）、释放踏板（挂起行为） | | |

| 13 | 直通与防卡死 | a) 作用域外通道、非目标 CC 消息过链；b) 发送 CC120、CC123（可插入 item 回放）；c) 让 CC123 落在换踏 gap 中 | 作用域外通道/非目标 CC 全直通；CC120/123 释放（含落在换踏 gap 中时：待踩沿取消、无幻影踩下，收敛轮 N3） | | CC120/123 额外安排一次自愈尾音兜底（见使用说明 §4.11） |
| 14 | CC 目标=66 | 高级页把 CC 目标改为 66，重复观察合并/防卡死/状态行 | 合并、防卡死、状态行跟随 | | |

| 16 | 跨播放启动 | a) 硬件踏板踩住时停止→播放；b) 总开关关时停止→播放 | 停止→播放，重发**合成值**（硬件踩住场景：踏板不掉，收敛轮 N2）；总开关关时不发任何消息；无卡死踏板 | | |
| 17 | 参数保持与 undo | 设好参数→保存并重开工程；点「恢复默认」→Ctrl+Z | 参数在重开工程后保持；恢复默认生成 undo 点 | | |

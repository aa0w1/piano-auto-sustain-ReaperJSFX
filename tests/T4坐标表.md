逐行复算方法：先算「设计坐标公式」列（纯设计单位，全部来自集中常量），再按布局引擎换算两档。

## 布局引擎（ui_frame_begin）

```
ui_sc = min(gfx_w / 380, gfx_h / 460)；ui_sc < 0.75 时钳为 0.75
ui_ox = (gfx_w − 380×ui_sc) / 2        （内容框水平居中）
ui_oy = (gfx_h − 460×ui_sc) / 2        （内容框垂直居中）
屏幕坐标 = ui_ox + 设计x×ui_sc；屏幕 y 同理；宽高 = 设计值×ui_sc
```

- **@380×460**：ui_sc = min(1, 1) = 1，ui_ox = ui_oy = 0 → 数值 = 设计值。
- **@760×920**：ui_sc = min(2, 2) = 2，ui_ox = ui_oy = 0 → 数值 = 设计值 × 2。
- 非 380:460 比例的窗口：等比取 min 后居中，多余边留白（设计取舍，见文末偏离记录 6）。

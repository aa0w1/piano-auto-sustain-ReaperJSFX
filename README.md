# Piano Auto Sustain (Reaper JSFX)

<p align="center">
  <img src="docs/img/ui-perf.png" alt="Piano Auto Sustain 界面" width="380">
</p>

> 弹 MIDI 键盘编曲时，自动替你踩延音踏板的 Reaper JSFX 插件。
> 复刻自 B 站 UP 主「[Amu音乐](https://www.bilibili.com/video/BV1kVJq6oE2D/)」开发的 Cubase MIDI Insert 插件《Piano Auto Sustain》，并针对 Reaper 的工作流做了增强。

适合键盘不带踏板、或不习惯边弹边踩踏板的编曲场景：你只管弹，延音踏板由插件按「低音锚定」规则自动踩、自动换。

## ✨ 功能特性

- **自动踩踏板** —— 弹下即踩，松手后延音保持一段时间（默认 2.4s）自然收掉
- **低音锚定换踏** —— 低音区出现新和弦音时自动「抬-踩」换踏；高音区琶音与旋律跑动**永不引起抖踏**（结构性保证）
- **录制即写 CC64** —— 布防到 Input FX 后，录制时生成的踏板直接写进 MIDI 条，事后可在钢琴卷帘里随意手改
- **硬件踏板合并** —— 偶尔插上真踏板也不打架：输出 = max(硬件, 自动) 合成单流
- **四页全定制界面** —— 演奏 / 高级设置 / 诊断 / 说明书，象牙琴房视觉
- **参数可调** —— 低音识别上限、延音尾长、换踏间隙、下踏人性化（±2ms 伪随机去机器味）、双限流窗、通道作用域、CC 目标（64/66/67）

## 🎹 安装（2 分钟）

1. 复制 `src/PianoAutoSustain.jsfx` 到 Reaper 效果器目录：
   - 标准版：`%APPDATA%\REAPER\Effects\`
   - 便携版：Reaper 安装目录下的 `Effects\`（如 `C:\REAPER\Effects\`）
2. **布防到 Input FX（监听 FX）**（推荐，录制时 CC64 直写进 MIDI 条）：
   选中音源轨 → 点 **Route** 按钮 → 路由窗口左上角 **Input FX** → 添加 `JS: Piano Auto Sustain (MIDI)`
3. Record Arm + 输入监听 → 直接弹。

详细步骤、截图与排查见 [docs/使用说明.md](docs/使用说明.md) 与 [docs/首载检查单.md](docs/首载检查单.md)。

## 🛠 参数速查

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 低音识别上限 | 59 (B3) | 0–127 | 低音区/高音区分界（换踏只由低音区触发） |
| 松弛后延音 | 2400 ms | 0–8000 | 全部琴键抬起后踏板保持的时长 |
| 换踏间隙 | 20 ms | 0–100 | 换踏时抬-踩之间的间隔，越大切音越干净 |
| 下踏人性化 | 12 ms | 0–50 | 踩下沿附加延迟与 ±2ms 抖动 |
| 低音换踏限流窗 | 250 ms | 0–500 | 两次低音换踏的最小间隔 |
| 重复音限流窗 | 120 ms | 0–500 | 同音重击触发换踏的最小间隔 |
| 和弦保护 | 开 | — | 关=简单模式（只踩-延-放，永不换踏） |
| 通道作用域 | 全部 | 全部/1–16 | 多音色 item 建议设单通道 |

## 📖 低音锚定怎么理解

换踏只由**低音区**（≤ 上限）的新音级触发，上限以上的音只「踩」不「换」——高音区的琶音与旋律跑动在结构上**永远不会抖踏**；右手长音 + 左手换和弦的糊音洞由低音锚定补上。调参原则与三个缓解手段见 [docs/使用说明.md 第 5 节](docs/使用说明.md)。

## ❓ 已知限制

- 右手独奏（无左手低音）换和弦不会自动换踏——可用「换踏一次」按钮救场（支持 MIDI learn 绑到键盘）
- Input FX 只处理实时输入：已录 item 的延音来自录进去的 CC64；回放含烘焙踏板的工程请关插件总开关
- 自动侧输出仅 0/127 两态（无自动半踏板）；硬件踏板的中间值原样透传

完整清单见 [docs/使用说明.md 第 7 节](docs/使用说明.md)。

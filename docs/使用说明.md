# Piano Auto Sustain — 使用说明

## 1. 这是什么

Piano Auto Sustain 是一个 Reaper JSFX 插件（MIDI 处理器）：挂在音源轨上，你只管弹 MIDI 键盘，它替你自动踩延音踏板——单音自动延音，左手低音区出现新和弦音时自动「换踏」（先抬一下再踩回），高音区的琶音和旋律跑动永远不会引起踏板抖动。适合键盘不带踏板、或不习惯边弹边踩踏板的编曲场景。

## 2. 安装

1. 把 `src/PianoAutoSustain.jsfx` 复制到 Reaper 用户效果器目录：
   - Windows：`%APPDATA%\REAPER\Effects\`（资源管理器地址栏直接粘贴回车即可打开）
   - Windows 便携版：Reaper 安装目录下的 `Effects\`（如 `C:\REAPER\Effects\`）
   - macOS：`~/Library/Application Support/REAPER/Effects/`（macOS 通用路径）
2. 打开（或重启）Reaper，在 FX 浏览器搜索 **Piano Auto Sustain (MIDI)**，确认它出现在列表里；若没有出现，刷新 FX 列表或重启 Reaper 即可。
3. 首次插入使用默认参数即可正常工作，无需任何配置。

装好后建议先跑一遍《首载检查单》（docs/首载检查单.md），约 5 分钟。

## 3. 快速上手（30 秒）

1. 在挂了钢琴音源的轨上打开 FX 链，把 Piano Auto Sustain 插到**乐器（音源）之前**——它要在音源收到音符之前处理 MIDI。注意：Reaper 默认把新加的 FX 排在已有 FX **之后**，加完请检查它是否在音源**上方**（不在就拖上去）。顺序放反的症状：插件界面踏板会动，但音源没有延音共鸣、录出来也没有 CC64。
2. 打开该轨的**输入监听**：轨面板点 Record Arm（录音布防），确认监听开着，弹琴出声。
3. 弹奏即可：
   - 弹一个音并松手 → 自动踩下，声音延住约 2.4 秒（尾音时长）后自然收掉；
   - 按住一个右手长音，左手换一个低音和弦 → 换和弦处听到踏板快速抬-踩（换踏）。

JSFX 不出声、不占音质，只处理经过它的 MIDI。想按自己的织体微调，先读第 5 节的低音锚定调参。

注：插件窗口按 380×460 等比缩放，缩放下限 0.75——更小的窗口会裁切底部按钮。

## 4. 功能详解

### 4.1 自动踩踏板

任何生效的音符都会触发一次「踩下」（目标 CC 输出 127）；踏板已经在下则无动作。

### 4.2 低音锚定换踏（和弦保护=开，默认）

- 插件维护一个「当前低音和声」：当前**按住**的所有低音区音符的音级集合（音级=不分八度的音名，C3 和 C4 算同一个音级）。
- 低音区（≤ 低音识别上限，默认 B3/59）出现**新音级**时：若踏板在下且不在低音限流窗内 → **立即换踏**，并开启低音限流窗（默认 250ms，窗内不再触发新换踏）。
- 踏板在上时，低音新音级只踩下、不换踏（换踏只发生在踏板处于下位时）。
- 上限以上的音（高音区）只触发踩下，**永不换踏**——这是结构性设计，详见第 5 节。

### 4.3 忽略八度变化（默认开）

只作用于低音区的换踏判定：开 = 低音同音级跨八度不算新和声（C3 按住时再弹 C2 不换踏）；关 = 跨八度也算新和声。高音区与本开关无关（高音本来就不换踏）。

### 4.4 重复音重踏（默认开，仅和弦保护=开时生效）

同一个键（同 pitch，任意音区）重复击键 → 触发一次换踏（若踏板在下），受**重复音限流窗**（默认 120ms）约束。同一击键同时命中重复音与低音新音级两条路径时，按重复音路径处理（只开重复音窗）。简单模式下此功能无效（UI 灰置）。

### 4.5 松弛后延音（默认 2400ms）

所有生效音符松开且无新音后，踏板再保持该时长（尾音）才释放。期间弹任何新音都会取消计时并正常处理——注意此时低音和声集合已清空，新音与空集合比较，所以「同和弦八度跳进恰跨全抬瞬间」会换踏，属预期行为。释放沿不受人性化延迟，即时抬起。

### 4.6 换踏间隙（默认 20ms，0–100）

换踏 = 先抬（=0）再踩下（=127）。抬沿即时、不受人性化；踩沿受人性化，且调度时刻不早于抬沿时刻 + 间隙（保证先抬后踩的顺序）。

### 4.7 下踏人性化（默认 12ms，0–50）

踩下沿额外延迟该毫秒数 + ±2ms 确定性伪随机（由音符与事件顺序决定，同样的演奏重放结果一致）。只作用于踩下沿，抬沿即时。作用是让自动踏板听起来更像人踩，而不是每次都精确到采样点。注：人性化为 0 时伪随机偏移仍在，但负侧会被钳位到 0，实际抖动为 0–+2ms，踩沿不会早于调度点。

### 4.8 硬件踏板合并（合成单流）

如果你同时踩了硬件踏板怎么办？本插件对作用域内的目标 CC **只输出一条合成流**：`合成值 = max(硬件值, 自动值)`——原来的目标 CC 消息被拦截改写，不再直通（音源只认最后到达的消息，两路并发会互相覆盖）。由此得到两条保证：

- 硬件踩住时，自动侧的抬沿**压不掉硬件**，输出保持 127；
- 硬件松开时，自动侧在下则保持 127。

诊断页可随时查看 硬件 / 自动 / 合成 三个真值。注意：自动侧只有 0/127 两态（无自动半踏板），硬件踏板的半踏中间值会原样透传进合成流。

### 4.9 简单模式（和弦保护=关）

任意音符踩下、全部琴键抬起后按尾音时长释放，**永不自动换踏**；重复音重踏在此模式下无效（UI 灰置标注）。适合纯旋律、或不想让插件频繁换踏的场景。

### 4.10 总开关（启用自动踏板，默认开）

- **关**：立即补发自动侧 0（若在下），并做一次软复位（清按住表 / 和声集合 / 调度器 / 计时器 / 挂起标志），此后**完全直通**——目标 CC 原样直通，只做跟踪，不拦截不合成。
- **开**：从「踏板释放」态起步。

### 4.11 防卡死：CC120 / CC123

收到 CC120（All Sound Off）或 CC123（All Notes Off）时，插件依次做三件事：

1. **自动侧立即释放**——若你同时踩着硬件踏板，合成流输出保持硬件值，硬件不会被压掉；
2. **清空状态并取消在途换踏**——清空按住表与和声集合，清调度器与计时器，取消正在等待中的换踏踩沿；
3. **额外安排一次自愈尾音兜底**——以防清态后仍有残留延音，再按尾音时长补一次自动释放。

消息本身仍直通给音源。目标 CC 改为 66/67 时，以上语义（合并/防卡死/状态行）同样跟随。

### 4.12 三个按钮

- **换踏一次**：踏板在下 → 立即切分一次（受换踏间隙/人性化影响，**不受**限流窗、不重开窗）；踏板在上 → 仅踩下；任何情况解除「释放挂起」。正在换踏途中（间隙/待踩沿）时被吸收、不排队。可绑 MIDI 控制器（见 5.4）。
- **释放踏板**：自动侧立即释放并进入**挂起**——挂起期间自动踩下/换踏/尾音计时全部暂停，间隙中的待踩沿取消；弹下一个音时自动解除挂起并正常处理。
- **恢复默认**：只把全部参数恢复为默认值，不动状态机/挂起标志/调度器，并生成一个 undo 点。

### 4.13 高级参数

- **通道作用域**（默认全部）：只处理选定通道的 MIDI，作用域外的全部原样直通。
- **CC 目标**（默认 64，可选 66/67）：延音踏板（64）/ 持续音（sostenuto，66）/ 弱音踏板（una corda，67）。全部相关语义跟随所选 CC。

## 5. 低音锚定的理解与调参

低音锚定是本插件的核心设计。理解以下五点，就不会有「这是不是 bug」的困惑。

### 5.1 为什么高音只踩不换（结构性设计，非 bug）

换踏只由低音区（≤ 低音识别上限）的新音级触发；上限以上的音只「踩」不「换」。这从结构上保证了高音区的同和弦琶音与旋律跑动**永远不会**抖踏。而右手长音 + 左手和声变化造成的糊音洞，正是靠低音锚定换踏来清理的。

### 5.2 低音区逐音（限流）换踏是特性——「泵动感」与三个缓解

低音区每出现一个新音级（受限流窗约束）就换一次踏，是特性不是缺陷。左手伴奏织体（如分解和弦、八度跳跃）会因此带有周期性的「泵动感」，这是低音锚定的固有代价。三个缓解手段：

1. **调大低音限流窗**：如 250 → 500，或按「约每拍换一次踏」的听感来调；
2. **上移低音上限**：让更少的音落入低音区，减少换踏次数（注意别把旋律圈进来，见 5.3）；
3. **切简单模式**（和弦保护=关）：完全退回「踩-延-放」。

### 5.3 低音识别上限怎么调

原则：**上限设在左手最高和声音之上、旋律最低音之下**。

- 旋律下探中音区 → 把上限下调，避免旋律音触发换踏；
- 纯右手独奏（没有左手伴奏）→ 可把上限调到极低（如 0），等效关闭锚定，插件退化为纯自动延音。

### 5.4 右手独奏的代价与「换踏一次」救场

右手独奏换和弦时，插件不会自动换踏——没有低音触发者，这是低音锚定的已知代价。救场办法：换和弦的瞬间点一下「换踏一次」按钮；更顺手的是绑到 MIDI 控制器上（MIDI learn 绑法）：

1. 在 FX 链中选中本插件，打开 FX 参数列表（FX 链右侧的 Params 面板）；
2. 找到「换踏一次」，右键 → **Learn single MIDI CC/note...**（官方菜单名；显示以你的 REAPER 版本为准）；
3. 按下你想绑定的键位 / CC / 音符即可完成绑定。

消费规则：插件只认 **0 → 非 0 的上升沿**（按下触发，松开不触发），所以不会因为松键产生误触发。

### 5.5 回放已烘焙 item 请关总开关

如果 item 里已经录好了踏板 CC（录法见第 6 节），回放这些工程时请把本插件的总开关关掉：否则自动侧会对回放的音符**二次生成**踏板，与已烘焙的 CC 冲突。

## 6. 把生成的踏板录进 MIDI

- **主推方法（Input FX / 监听 FX）**：把插件放到音轨的 **Input FX（监听 FX）** 区（轨面板的「IN FX」），录音布防并打开输入监听，开录音实时弹奏——生成的踏板 CC 会随你的输入一起录进 item。这是把踏板写进 MIDI 的推荐路径。
- **普通 FX 链位 = 仅实时**：插件挂在普通 FX 链（乐器前）时只在监听/播放时实时起作用，**不会**写入 item。
- **已录制 item 的回放烘焙路径**：把已录好的 item 重新烘焙出带踏板 MIDI 的具体操作路径，**按你的 REAPER 版本核验**后再使用（不同版本菜单与行为有差异），本说明不写死该步骤。回放含已烘焙踏板的工程时，请关闭总开关（见 5.5）。

## 7. 已知行为与限制

1. **transport 停止时的运行行为随版本/位置而异**：REAPER 7+ 在 UI 可见时，即使播放停止 FX 也持续运行（尾音计时器在停止状态下继续走）；REAPER 6 需要轨道处于 record-arm（录音布防）状态才持续运行；挂在 item/take 上的 FX 只在 item 播放时运行。
2. **采样率变化**（切换音频设备、修改采样率）时，正在等待中的延时踩沿（换踏间隙/人性化）会出现一次性时长偏差，之后恢复正常。
3. **总开关关闭期间点击的按钮**（换踏一次/释放踏板）不会立即生效，会在重新打开总开关后立即生效（下一个音频处理块内）；若保存工程瞬间按钮命令槽恰好为 1，重开工程的首块还会触发一次（罕见场景）。
4. **velocity=0 的 Note On 按 Note Off 处理**（部分控制器/音源以这种方式发松键消息，属正常处理）。
5. **通道作用域=全部 + 多通道 item**：状态机全通道共享，跨通道同名音符（同键位）计数共享、多乐器会互相触发踏板；释放沿与重同步消息发往作用域内最近发过自动踩下的**所有**通道。多音色 item 建议把作用域设为单通道，或分轨。
6. **生成 CC 的输出通道**跟随触发音符所在通道（作用域内）。
7. **按钮与命令槽**：按钮动作不写入自动化包络（无回放误触发）；MIDI learn 绑定不受影响（走宿主侧参数映射）；极快连点可能丢一次（音频块粒度）。
8. **无自动半踏板**：自动侧只有 0/127 两态；硬件踏板的中间值（半踏）原样透传进合成流。
9. **变参时机**：调整「低音识别上限」或「通道作用域」时若有琴键按住，内部计数不会重算——可能漏一次换踏或尾音不启动。建议改参数前先松开所有琴键，或发一次 CC120/123（或开关一次总开关）复位。
10. **作用域≠全部时的重同步目标**：通道作用域设为单通道时，重同步/按钮兜底消息固定发往通道 1（插件约定，非 bug）。
11. **CC 目标中途切换**：从 CC64 改到 66/67 时，旧的 64 不会自动清零（下游音源里 64 维持最后值）。
12. **极小尾音参数**：尾音时长 ≤ 人性化+换踏间隙之和时，换踏待踩沿会被尾音兜底取消（极端参数边缘，正常听感无影响）。
13. **诊断页口径**：诊断页「发送计数」包含重同步补发；事件日志中的「重同步」条目是状态补发记录，不代表踩/抬动作。
14. **事件日志通道号**：诊断页事件日志中的通道号为 0–15（0 基，MIDI 通道 1 显示为 ch0），与 REAPER 界面的 1–16 通道号差一，对照时注意。

## 8. 常见问题 FAQ

**Q1：弹了但踏板不抬 / 声音一直延？**
依次排查：① 打开诊断页看「合成」值是否长期 127——若是，检查是不是还有音没松（尾音计时没启动）；② 是否点过「释放踏板」按钮进入挂起（弹一个新音即解除）；③ REAPER 6 停止播放时轨道未 record-arm，FX 不运行（见 7.1）；④ 硬件踏板是否一直踩着（合成流取 max，硬件踩住自动侧抬不下去）。

**Q2：高音为什么不换踏？**
结构性设计，非 bug：换踏只由低音区新音级触发，保证高音琶音/旋律永不抖踏（见 5.1）。需要高音换踏时，用「换踏一次」按钮或 MIDI learn 绑键救场（见 5.4）。

**Q3：左手伴奏有「泵动感」？**
低音区逐音（限流）换踏的固有代价，是特性。三缓解：调大低音限流窗（≈每拍换踏）/ 上移低音上限 / 切简单模式（见 5.2）。

**Q4：硬件踏板是不是被插件压住了？**
不会。插件对目标 CC 只输出一条合成流 max(硬件, 自动)：硬件踩住时自动侧抬不下去，硬件永远不会被自动侧压掉（见 4.8）。若感觉异常，看诊断页「硬件」真值确认硬件消息是否到达插件（检查通道作用域设置）。

**Q5：换和弦还是糊？**
检查低音识别上限是否盖住了左手和声：上限应设在左手最高和声音之上、旋律最低音之下（见 5.3）。若左手快速跑动导致换踏太密（泵动感），按 5.2 的三缓解处理：调大低音限流窗、上移低音上限或切简单模式。

**Q6：怎么把生成的踏板录进 item？**
用 Input FX（监听 FX）法：插件放轨道 Input FX 区 → 开输入监听 → 开录音实时弹奏，CC 随输入进 item（详见第 6 节）。普通 FX 链位只实时生效，不写入 item。

**Q7：全抬手瞬间接一个八度跳进，为什么换了踏？**
松弛延音期间低音和声集合已清空，新音与空集合比较，所以「同和弦八度跳进恰跨全抬瞬间」会换踏，属预期行为（见 4.5）。

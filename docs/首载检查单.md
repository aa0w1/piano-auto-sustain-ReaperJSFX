# Piano Auto Sustain — 首载检查单（约 5 分钟）

首次安装后按顺序勾选；任一步不过时，若伴随 JSFX 编译错误按第 ⑧ 项模板记录，其余直接反馈现象。

- [ ] **① 复制文件 → FX 列表出现插件**
  把 `src/PianoAutoSustain.jsfx` 复制到效果器目录（标准版 `%APPDATA%\REAPER\Effects\`；便携版如 `C:\REAPER\Effects\`）；打开/重启 Reaper，FX 浏览器搜「piano auto」→ 列表出现 **Piano Auto Sustain (MIDI)**。
  （□ 通过 □ 异常：＿＿＿＿）

- [ ] **② Input FX 布防 → UI 截图对照**
  新建轨挂任意钢琴音源 → 选中轨道 → 点 **Route** 按钮 → 路由窗口**左上角 Input FX** → 添加 **JS: Piano Auto Sustain (MIDI)** → 关闭路由窗。
  主 FX 链里**不要**再放一份（两处同放会重复处理）。
  然后从轨面板 Input FX 区打开插件窗口，对照**演奏页**应见：
  - 踏板图形（踩下/抬起两态，带位移动画）；
  - 总开关（启用自动踏板）；
  - 两大参数卡：低音识别上限（数字+音名+加减）、松弛后延音（数字+ms+加减）；
  - 两个开关：和弦保护、忽略八度变化；
  - 三个按钮：换踏一次、释放踏板、恢复默认；
  - 底部状态行（音符数 / 目标 CC 合成值）。
  建议截图留档：＿＿＿＿

- [ ] **③ 弹单音听延音**
  轨 Record Arm + 输入监听开启 → 弹一个音并松手 → 声音延住约 2.4 秒（默认尾音）后自然收掉。
  （□ 通过 □ 异常：＿＿＿＿）

- [ ] **④ 弹低音换和弦听换踏**
  按住右手一个长音 → 左手先后弹两个不同和弦的低音 → 每个新和弦处听到快速抬-踩（换踏），右手长音不受影响。
  （□ 通过 □ 异常：＿＿＿＿）

- [ ] **⑤ 录制闭环：CC64 写进 item**
  直接录制弹 8 个音左右 → 停止 → 双击录出的 item 打开钢琴卷帘 → 左侧 CC 参数列表选 **CC64** → 应看到台阶线（127=踩、0=放、换踏处快速下-上）→ 拖动一处台阶的位置 → 回放确认手改生效。
  若界面踏板会动但 item 里没有 CC64 → 插件不在 Input FX（见 ② 重新布防）。
  （□ 通过 □ 异常：＿＿＿＿）

- [ ] **⑥ 诊断页三真值与计数**
  切到诊断页：踩硬件踏板 →「硬件」=127；弹音 →「自动」=127；「合成」=max(硬件,自动)；按住音符数与 CC 发送计数随弹奏增长。
  （□ 通过 □ 异常：＿＿＿＿）

- [ ] **⑦ 说明书页目视核对**
  切到说明书页：安装路径两行的反斜杠（如 `%APPDATA%\REAPER\Effects`）渲染正确、无异常字符（出现 `?`、多余转义或路径断裂记为异常）。
  （□ 通过 □ 异常：＿＿＿＿）

- [ ] **⑧ 若 JSFX IDE 报编译错误（仅报错时）**
  FX 链选中本插件 → Edit 打开 JSFX IDE；若有编译错误，按下方模板记录后反馈：

  ```
  【JSFX 编译错误汇报】
  - 行号：
  - 错误文本（原文照抄）：
  - 出现时机（插入时 / 改参数时 / 播放时）：
  - Reaper 版本：
  ```

全部勾完 → 首载通过，可日常使用并跑 `tests/测试清单.md`；任一步未过 → 按开头方式反馈（有编译错误附 ⑧ 记录）。
